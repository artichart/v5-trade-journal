# สมุดไม้จริง XAUUSD

สมุดบันทึกการเทรดที่มีจุดประสงค์เดียว: **ทำให้เทรดเดอร์ทำตามระบบ**
ไม่ใช่รายงานสถิติย้อนหลัง — สถิติเป็นผลพลอยได้

รันบน localhost อย่างเดียว · **zero dependency** (`node:sqlite` + `node:http` + SVG ที่วาดเอง)

```bash
npm start          # ของจริง       → http://127.0.0.1:4173
npm run demo       # ข้อมูลสังเคราะห์ → http://127.0.0.1:4199  (ไม่แตะ data/journal.db)
```

ต้องใช้ Node ≥ 22 (`node:sqlite` เป็น built-in ตั้งแต่ 22)

## ทำไมถึงหน้าตาแบบนี้

ตัวเลขจริง 4 เดือนบอกว่าเดือนหนึ่งถูกตัดสินด้วยไม้ไม่กี่ไม้ที่ **ขนาดไม้เกินแผน 3–12 เท่า**
ไม่ใช่ด้วยคอนฟิกของระบบ → เครื่องมือจึงต้องอยู่ตรงนั้น **ตอนกำลังจะกดเข้าไม้** ไม่ใช่ตอนรีวิว

### 1. หน้างาน — ตอบคำถามเดียว "ตอนนี้กดเข้าได้ไหม และตั้งเท่าไหร่"
- กรอกราคา + ATR → คิด **lot / ระยะ / SL / TP** ให้ (สูตรตรงกับ Pine ตัวที่ยิงสัญญาณ)
- **lot ปัดลงเสมอ** — ปัดขึ้นแปลว่าเสี่ยงเกินที่ตั้งใจ
- ถือไม้อยู่ หรือโควตาวินโดว์หมด → **ซ่อนเครื่องคิดเลขทั้งอัน** (โชว์ไว้เท่ากับชวนให้คิดต่อ)
- กดปุ่มเดียวบันทึกไม้ลงสมุด → **การจดเป็นผลพลอยได้ของเครื่องมือที่ต้องใช้อยู่แล้ว**

### 2. วินัย แยกจากกำไร
เทียบ "ที่ตั้งใจ" (จากระบบสัญญาณ) กับ "ที่ทำจริง" (จาก MT4) แล้วติดธงเอง ไม่ต้องให้ใครรายงานตัวเอง:
เข้าก่อนสัญญาณ · lot เกินแผน · เข้าหลายไม้ · **ขยับ SL/TP** · ปิดมือ

### 3. สถิติที่อ่านแล้วไม่หลอกตัวเอง
- **R-multiple** — ไม้ lot เกินแผน 4 เท่าโผล่เป็น −4R ทันที ไม่ซ่อนอยู่ในยอดรวม
- **Equity ทำจริง เทียบ ตามแผน** — ช่องว่างระหว่างสองเส้นคือราคาของการไม่ทำตามแผน
- **Win % / Expectancy มี ±SE เสมอ** — ส่วนต่างที่เล็กกว่า 2 SE อ่านว่า "ยังแยกไม่ออก"
- **สถิตินับต่อระบอบกติกาเท่านั้น** ไม่มี endpoint ไหนรวมข้ามระบอบได้ (บังคับที่ schema)
- ไม้ที่ **ปิดมือ** ไม่ปนกับไม้ที่จบตามกฎ — คนละประชากร

### 4. Freeze gate
ห้ามแก้คอนฟิกจนกว่าไม้ที่จบด้วย TP/SL จะครบตามเกณฑ์ (ค่าเริ่มต้น 20)
ที่ 20 ไม้ SE ของ Win % ยัง ≈ 11 จุด — ต่ำกว่านั้นแยก noise ไม่ออกอยู่ดี
ข้อยกเว้นเดียวคือบั๊ก "แพ้ 2 ไม้ติด" ไม่ใช่บั๊ก

## โครงสร้าง

```
src/analytics.js   ฟังก์ชันล้วน — R, plan P&L, ธงวินัย, equity/DD, expectancy±SE, เครื่องคิดแผน
src/db.js          schema + query (node:sqlite) · ruleset_id NOT NULL = กันสถิติปนข้ามระบอบ
src/server.js      API + static (node:http)
public/charts.js   SVG chart ที่วาดเอง — ทุกกราฟมีตารางคู่แฝดและ tooltip
scripts/seed-demo.js  ข้อมูลสังเคราะห์ (ปฏิเสธเองถ้า JOURNAL_DB ชี้ DB จริง)
scripts/preview.js    เรนเดอร์กราฟเป็น HTML นิ่งไว้แคปดูด้วยตา
```

`data/journal.db` ไม่ถูก track — ข้อมูลการเทรดอยู่บนเครื่องเท่านั้น

## ค่าที่ต้องตรงกับสคริปต์สัญญาณเสมอ

ตาราง `settings`: `risk_usd` · `sltp_mult` · `sltp_step` · `sltp_min_dist` · `max_per_session`
ถ้าสองฝั่งค้างคนละค่า เครื่องคิด lot จะบอกเลขคนละชุดกับเส้นบนกราฟโดยไม่มีอะไรฟ้อง
